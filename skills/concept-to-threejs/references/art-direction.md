# 布局与生图提示词

## 三个空间问题

先为三个可行方案各写一句空间设想。例：同一个潮汐档案馆，可以沿堤岸一字展开，便于玩家在转角发现主楼；可以围绕天井布置，使玩家一路看见对岸；也可以跨高低两层水道，让同一座桥分别成为远处地标与近处天花。为实际题材另想三种。三案沿用相同的尺度参照、画幅、色调和俯视角，便于比较。每案都能用一句话说出玩家从哪里出发，经过什么，又从哪里回望。

**布局生图提示词示例**（把实际概念图作为图像输入）

> 根据所附潮痕、灰青混凝土与琥珀色玻璃的概念图，画一张被海水侵入的潮汐档案馆布局设计图。采用向天井聚合的方案。以略高的三分之四视角容纳整个场地，西南入口、跨水窄桥、东侧主楼和屋顶回廊都可见。保留概念图中透过雾气的暖窗。用门洞和楼梯交代人的尺度，使桥两头的落点、绕行巷和水面高差清楚可辨。画成统一的空间，不加文字或分格。

看图时沿入口到地标在画上走一遍，再试一次反向观察。比较概念图的辨识度、近中远景的层次、路线和地标的可读性，以及能否用实际几何搭出接缝和遮挡。记录三个候选各自最有说服力的一点和主要代价。默认由主 agent 指出最终选哪个、为什么；用户要亲自选时，交付三个候选和取舍，等用户决定后再建灰模。某张图若画丢了作品不可缺少的地标或把两条路线混为一条，应针对该问题修图再比较。保存三个独立可看的候选图，以及与其匹配的实际提示词。

## 生成可交接的分区参考

主 agent 将总布局中该区的位置、相邻地标和灰模视角一起给生图工具。沿用同一套尺寸与材质词，按建模疑点选择视图。例如空间难读时用斜俯视加侧剖面，灯具或承重结构难读时用连接处近景。构图中留出区域的两个边界。视图里的尺度歧义由主 agent 对照灰模解决，再把约定写进交接。

**分区生图提示词示例**（附选中布局、该区灰模截图与概念图）

> 为图中窄桥到东侧档案主楼门廊的区域绘制建模参考。保持灰模中桥面与门槛同高、桥墩位置及桥下航道净空，沿用灰青混凝土和琥珀玻璃。主视图从桥的侧前方看向门厅；另给同一接头的侧视局部，让建模者看清桥板如何坐进支座、石栏在哪里收头。给地面一盏中性侧光，使构件轮廓、前后顺序和材质接触线清晰。

保存实际生图和提示词，用短区域名配对并检查文件可读。图中方案与灰模冲突时，先决定调整哪一处，更新相关区域的交接；保持主图、分区图和建模约定指向同一个版本。
