# 分区建模交接

先用选定的布局图搭一个共用灰盒，锁定主视角和能走通的路线。按可以单独建模、在明确位置接回场景的部分划区。门洞、桥头、楼梯口等交接处，在灰盒上标出两端坐标、完成面高度、净空和构件归属。全程沿用项目的坐标系、比例和材质命名。

每区用原概念图、选定布局和该区灰盒视图生成一张区域参考图。取景带上相邻区的一小段，并保留可辨认的尺度参照物。主代理打开生成结果，核对入口、轮廓、方向和相邻关系，必要时重生。派工时附上**实际生成的图、生成时使用的完整提示词、选定总图和灰盒**。通过附件或子代理可读取的项目相对路径交付。效果图决定造型和材质意图，灰盒决定尺寸和连接位置。

## 可复制的单区任务单

以下以展馆入口为例，路径、尺寸、材质和验收容差都随项目替换。引用的图片应在实际派工前生成并打开核对。

```text
任务 A03 · 展馆入口前厅 · 灰盒 v3
交付可装入 Three.js 的前厅模型。保留概念图中的深窗洞、磨砂铝门套与深灰水磨石。主视角由前厅朝东看向展厅。

附件
  选定总图 concept/selected.png，区域生成图 concept/a03-v3.png，灰盒 layout/v3.glb。
  区域图生成提示词全文「依据所附总图与前厅灰盒，从西侧入口朝东看。保留方形前厅、深窗洞与东墙中央的单个无门扇通口。画入门外一段展厅地面。磨砂铝门套、深灰水磨石，自然漫射光。水平视角，能看清门框厚度和地面接缝。」

定位
  项目右手系，1 单位 = 1 米，+Y 向上，+X 向东。坐标按 (x,y,z) 书写。
  A03 地面覆盖 x=-6…0、z=-3…3，完成面 y=0。模型根节点位于西入口中心 (-6,0,0)，不旋转，缩放为 1。下列尺寸均为世界坐标，导出顶点使用根节点局部坐标。

与 B01 展厅的接口
  东墙中心线 x=0。门洞地面锚点 (0,0,0)，通行净宽 2.4 m、净高 2.7 m，门套内缘在 z=±1.2，洞口上缘 y=2.7。
  A03 独自制作整面东墙、门套和门槛石。门槛顶面 y=0，沿 x 从 -0.10 到 +0.10，沿 z 从 -1.2 到 +1.2。洞内两侧地面分别在 x=-0.10 和 +0.10 收边，B01 从东侧贴合。门槛下方两侧均留槽。
  人行线沿 z=0 从 x=-5 通往 x=+2。保留 1.8 m 宽、2.2 m 高的通行空间，装饰和碰撞体均在其外。

文件与渲染
  A03 只写 zones/a03/，交付 zones/a03/foyer.glb 与同目录验收图。B01 只写 zones/b01/。主代理持有场景入口、共享材质表和烘焙装配代码。
  材质沿用 M_TERRAZZO_DARK 和 M_ALU_SATIN。固定墙、地面与门套标为静态，参与光线追踪烘焙。可移动导览牌标为动态，使用运行时照明与阴影。静态烘焙时移出导览牌，移动后原位应无残影。

验收回传
  返回模型路径、根节点变换和实际测得的门洞净宽/净高。由 (-5,1.6,0) 望向 (0,1.6,0) 截主视图。与 B01 灰盒拼装后截门槛近景，沿人行线穿过门洞，查看裂缝、重面闪烁和碰撞阻挡。两侧地面与门槛高差目标 ≤ 5 mm。
  附本轮实际截图路径、实测值和待处理问题。若只能单区预览，注明待主代理在完整场景验证的接口。
```

## 并行与合并

每个独立区域交给一个建模子代理。先把同一版灰盒和相邻区接口发给双方。并发名额不足时按依赖分批，优先派发定义公共接口的区域，其余排队。等待邻区实模期间，可以用已锁定的接口灰盒拼装。没有可用子代理时，先完成仍可执行的图稿与任务单，说明无法独立派工；用户接受串行建模时沿用同一套接口。

接口需要改动时，子代理报出旧值、新值、原因及受影响邻区。主代理更新灰盒版本，把变更同步给相关负责人，按需要重生区域图。合并后由主代理加载实际区块，复走相机路线，以同一机位比对概念图、灰盒和成品。接缝改动后重测通行与地面高差，静态几何或光照改动后重算受影响的烘焙结果。
